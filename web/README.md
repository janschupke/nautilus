# Nautilus (Next.js)

The interactive lab UI lives in this directory. **Setup, Docker, course layout, and authoring rules** are documented in the **[repository root README](../README.md)**.

## Quick commands

```bash
npm install
npm run dev                # webpack dev server; starts at 3000, then uses next free port
npm run dev -- --port 4000 # fixed dev port
npm run dev -- --turbo     # optional Turbopack experiment
npm run build
npm test
npm run test:e2e
npm run check
npm audit
```
