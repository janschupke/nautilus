# Nautilus (Next.js)

The interactive lab UI lives in this directory. **Setup, Docker, course layout, and authoring rules** are documented in the **[repository root README](../README.md)**.

## Quick commands

```bash
npm install
npm run dev       # starts at PORT or 3000, then uses the next free port if needed
npm run build
npm test
npm run test:e2e
npm run check
npm audit
```
